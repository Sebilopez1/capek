# Developer and crew records

Internal history of how Capek was planned, built and reviewed. Users don't need anything here.

- `STATUS.md`: the running crew log, newest session first.
- `RELEASE.md`: the release checklist (0.2.0 first, the 0.1.0 checklist below it).
- `research-brief.md`, `phase*-research-brief.md`, `phase*-plan.md`: research and plans for each build phase.
- `reviews/`: QA reviews. `milestones/`: phase-end reports.

These files keep the project's old name, Robot Report Card (`rrc`), where they describe work done before 0.2.0.

Paths written inside these records (for example `STATUS.md`, `docs/reviews/...`) predate the move to `docs/dev/`.
