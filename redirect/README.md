# robot-report-card is now Capek

Robot Report Card was renamed to **Capek** in version 0.2.0. This package only installs the new one.

```bash
pip install capek-tech            # or capek-tech[score], [sim], [eval], [lerobot]
capek score path/to/lerobot_dataset
```

The command is now `capek` (it was `rrc`). Sessions, datasets, checkpoints and reports written by 0.1.0 still load.

Project page: https://github.com/Sebilopez1/capek
